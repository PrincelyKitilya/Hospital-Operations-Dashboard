# 🏥 Hospital Management Analytics Dashboard

A cloud-connected hospital analytics dashboard built using Streamlit and PostgreSQL (Supabase).  
This project demonstrates database design, SQL analytics, and cloud deployment of a real-world hospital management system.

---

## Tech Stack

- Python
- Streamlit
- PostgreSQL
- Supabase (Cloud Database)
- SQLAlchemy
- Plotly

---

## Core Features

### Executive Overview

- High-level hospital KPIs
- Total patients, doctors, appointments
- Revenue and performance summary
- Real-time metrics pulled from PostgreSQL

---

### Doctor Analytics

- Doctor workload analysis
- Appointment distribution
- Performance tracking
- Revenue contribution per doctor

---

### Financial Insights

- Revenue trends
- Department-level financial performance
- Appointment billing analysis
- Aggregated SQL-based financial metrics

---

### Patient Analysis

- Patient demographics
- Visit frequency
- Appointment trends
- Data-driven insights using SQL queries

---

### Raw SQL Queries

- Custom SQL queries for advanced analysis
- Aggregations and joins
- Grouped performance metrics
- Direct PostgreSQL querying via SQLAlchemy

---

## Database Architecture

- Designed locally in PostgreSQL
- Migrated to Supabase (cloud-hosted PostgreSQL)
- Secure database connection using Streamlit secrets
- Cloud-ready architecture
